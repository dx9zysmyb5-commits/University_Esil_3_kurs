# Учебный архив — 3 курс

Учебное портфолио студента Esil University: лабораторные работы, практические задания и проекты.

## Дисциплины

1. [Основы микропроцессорной техники (ОМТ)](OMT/)
2. [Графические методы защиты веб-приложений](Graphic-Web-Application-Protection/)
3. [Разработка стартапа](Startup-Development/)
4. [Объектно-ориентированное программирование (ООП)](OOP/)
5. [Big Data](Big-Data/)

## Как устроен архив

- В разделе ОМТ будут размещены ссылки на выполненные лабораторные работы.
- В остальных разделах будут храниться файлы лабораторных работ и учебные материалы.
- Главная страница сайта находится в файле [index.html](index.html).

Материалы будут добавляться по мере загрузки файлов и получения ссылок.
